# HNET — Holographic Network Field Theory

A conceptual framework about what reality is made of, by David. The ideas are David's. AI tools helped with the wording and with checking the ideas against established physics, but did not supply them.

Core axiom: reality is a dynamic, self-referential substrate of distributed relational information, restructured by events.

HNET has no mathematics yet and makes no prediction that differs from standard physics. It is a proposed underlying picture, not a confirmed or new physical theory. Being compatible with existing physics is not the same as being confirmed by it.

## What's here

- [HNET.md](HNET.md): the current framework, as of October 6, 2026.
- [simulator/](simulator/): a toy simulator (`hnet_sim.py`) and a report on its first runs. It is a stress test of the concepts, not validation of HNET. Every number in it comes from placeholder settings. Run it with `python simulator/hnet_sim.py` (standard Python 3.11, nothing to install).
- [early-version/](early-version/): the November 2025 version of HNET, kept for the record. It is superseded. Several of its ideas were dropped or reworked, and it does not describe the current framework.
